Support Ticket Intelligence – Test Scenarios

1. Objective

To verify support ticket creation, priority updates, and status handling in the Salesforce project.

2. Test Cases

Test ID| Test Scenario| Expected Result
TC-01| Create a support ticket with valid details| Ticket should be created successfully
TC-02| Create a ticket for a login issue| Ticket details should be stored correctly
TC-03| Trigger the priority update Flow| Priority should update according to configured conditions
TC-04| Update the ticket status| Updated status should be saved
TC-05| Create a ticket with missing required information| Salesforce should enforce configured validation rules
TC-06| Verify ticket details after saving| Saved fields should display the correct values

3. Testing Status

Testing will be performed as the project features are completed.

4. Notes

These are planned test scenarios. Actual results should be recorded after executing each test in Salesforce.
