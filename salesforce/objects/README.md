# Support Ticket Intelligence — Salesforce Object

## Project Overview
Support Ticket Intelligence is a Salesforce-based customer support project designed to store support ticket details and automate ticket handling.

## Custom Object
- **Object Label:** Support Ticket Intelligence
- **Purpose:** Store and manage customer support tickets.

## Fields
| Field Label | Purpose |
|---|---|
| Support Ticket Intelligence Name | Identifies the ticket record |
| Owner | User who owns the record |
| Description | Additional ticket details |
| Issue Type | Category of the reported issue |
| Priority Level | Ticket priority |
| Status | Current ticket status |
| Ticket Subject | Short description of the issue |
| Customer Email | Customer's email address |
| Customer Name | Customer's name |

## Notes
This file documents the intended object structure. Verify field API names and data types in Salesforce Setup before treating this document as the final technical specification.
